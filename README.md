# ASSIGNMENT-mysql1
Employee Database Management System – MySQL

📌 Project Overview

This project demonstrates the creation and management of an Employee Database using MySQL Workbench.

The project focuses on practising SQL Data Definition Language (DDL) commands, creating tables, modifying table structures and implementing different constraints to maintain data integrity.

🛠️ Tools Used

* MySQL
* MySQL Workbench
* SQL

🗄️ Database Structure

Database Name: employee

The database consists of three tables:

1. Employees

Stores employee-related information.

Columns include:

* employee_id
* employee_name
* gender
* date_of_joining
* designation
* department_id
* location_id
* salary
* email

2. Departments

Stores department information.

Columns:

* department_id
* department_name

3. Location

Stores location-related information.

Columns:

* location_id
* location
